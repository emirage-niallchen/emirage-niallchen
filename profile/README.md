# Profile artwork

The header uses the official Makima character illustration from the [Chainsaw Man TV anime character page](https://www.chainsawman.dog/tvseries/character/).

- Original image: [chara_2_stand.png](https://www.chainsawman.dog/tvseries/assets/img/chara/chara_2_stand.png)
- Character artwork: © Tatsuki Fujimoto / Shueisha, MAPPA.
- The original PNG is embedded in `makima-header.svg` so the header does not depend on an external image request. Its proportions are preserved; the SVG frame crops the character to a portrait.
- Palette: charcoal `#171416`, oxblood `#8F2938`, muted red `#C65B62`, ivory `#F2E8DC`, gold `#D6AE71`.

The blog badge uses the avatar supplied and confirmed by the profile owner. The character artwork is used for the page theme.

GitHub statistics are refreshed by the profile-stats workflow. The contribution snake has matching light and dark palettes. The latest blog dates use the Asia/Shanghai timezone; the “最近的我” section and two selected essays are maintained manually.
